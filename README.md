# SplitPesa — M-Pesa Bill Splitter

A full-stack TypeScript web application (React + Vite + Tailwind CSS + Express) for splitting bills among friends and tracking real-time Safaricom Daraja M-Pesa STK Push payments.

## Tech Stack
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend**: Node.js, Express 5, TypeScript (`tsx`), Axios, MySQL (`mysql2/promise` with automatic in-memory fallback)
- **Payments**: Safaricom Daraja M-Pesa Express (STK Push) API with built-in sandbox simulation
